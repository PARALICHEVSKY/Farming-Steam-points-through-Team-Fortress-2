# Farming-Steam-points-through-Team-Fortress-2

**Farming Steam Points through Team Fortress 2**: buy Mann Co. Supply Crate Keys in TF2's in-game store to earn Steam Points, then sell the keys on the Steam Community Market to recover part of the cost as Steam Wallet funds. Repeat the cycle to accumulate points while tracking the loss on each key.

---

## Что это и зачем

За покупки в Steam дают **очки Steam**: 100 очков за каждый потраченный $1. Их можно тратить на аватарки, фоны и другое оформление профиля.

Программа делает за вас так:

1. покупает **ключи от ящиков Манн Ко.** в магазине TF2 с вашего кошелька Steam, и за это начисляются очки;
2. сразу продаёт эти ключи на **Торговой площадке Steam** по самой низкой цене, чтобы вернуть на кошелёк большую часть денег;
3. повторяет это столько раз, сколько скажете, и считает, сколько вы потеряли и сколько очков получили.

> ⚠️ **Это не заработок.** С каждого ключа вы теряете примерно 15–25%: Торговая площадка берёт комиссию, и ключ там стоит дешевле, чем в магазине. Фактически вы **покупаете очки Steam дешевле**, чем обычно. Сколько стоят 100 очков, программа показывает до покупки.

## 🚀 Быстрый старт (Windows)

### Шаг 1. Установите Node.js (один раз)
1. Зайдите на **https://nodejs.org/**
2. Нажмите большую зелёную кнопку **LTS** и скачайте установщик.
3. Установите его, везде нажимая **Next**.

### Шаг 2. Скачайте программу
1. Вверху этой страницы нажмите зелёную кнопку **Code**, затем **Download ZIP**.
2. Распакуйте архив в любую папку, например на рабочий стол.

### Шаг 3. Запустите
Откройте папку и **дважды кликните `start.bat`**.

При первом запуске программа сама скачает нужные файлы (1–2 минуты) и проведёт по настройке. Нужно будет ввести:

| Что спросит | Что вводить |
|---|---|
| Логин Steam | имя, которое вводите при входе в Steam (**не** ник) |
| Пароль | пароль от Steam. Вместо букв будут звёздочки, это нормально |
| Steam Guard | **1**, если у вас обычное приложение Steam на телефоне (так у большинства) |
| Цена ключа | цена «Ключа от ящика Манн Ко.» в магазине TF2, как там написано (например `2.49`). Не знаете — нажмите Enter |

> 🔒 Логин и пароль хранятся **только на вашем компьютере**, в файле `.env` в папке программы. Отправляются они только в сам Steam. **Никому не отправляйте файл `.env` и папку `data`.**

### Шаг 4. Пользуйтесь меню

```
  1 — Проверить цены (ничего не покупает)
  2 — Пробный запуск (деньги не тратятся)
  3 — Запустить фарм (тратит деньги!)
  4 — Продать ключи, купленные раньше
  5 — Подтвердить лоты на Торговой площадке
  6 — Статистика
  7 — Статистика в браузере
  8 — Настройки (логин, пароль, Steam Guard, цена ключа)
  0 — Выход
```

Введите цифру и нажмите **Enter**.

**В первый раз делайте по порядку:**

1. **Пункт 1.** Посмотрите, сколько теряется на ключе и сколько стоят 100 очков.
2. **Пункт 2.** Пробный запуск: программа войдёт в аккаунт и покажет, что сделала бы, но **ничего не купит**.
3. **Пункт 3.** Настоящий фарм. Для начала укажите **1 ключ** и **1 раз**. Перед покупкой программа покажет сумму и спросит «да/нет».

Когда программа входит в Steam, она может попросить **код Steam Guard**: откройте приложение Steam на телефоне и введите код оттуда.

После выставления ключей на продажу откройте приложение Steam на телефоне → **Подтверждения** и подтвердите лоты. Если у вас есть maFile (см. ниже), это произойдёт само.

## ❓ Частые вопросы

**Что нужно на аккаунте?**
- Деньги на кошельке Steam.
- Мобильный Steam Guard, включённый **больше 7 дней** назад. Иначе Steam задерживает продажи на Торговой площадке.
- Аккаунт не должен быть ограничен (нужна хотя бы одна покупка в Steam на $5+).

**Нужно ли запускать TF2?**
Нет. Программа сама подключается к TF2 через Steam, но TF2 должен быть у вас в библиотеке (игра бесплатная).

**«Неверный логин или пароль»**
Выберите пункт **8** в меню и введите данные заново.

**«Steam временно заблокировал вход»**
Было слишком много попыток входа. Подождите 30–60 минут.

**Программа просит подтвердить покупку по ссылке**
Значит, автоматическое подтверждение не сработало. Откройте показанную ссылку в браузере, где вы вошли в Steam, и нажмите «Подтвердить». На это есть 5 минут, потом покупка отменится и деньги не спишутся.

**«GC отклонил покупку: InvalidParam»**
Неверная цена ключа. Проверьте цену в магазине TF2 и исправьте её в пункте **8**.

**Сколько денег вернётся и когда?**
Деньги за ключ придут на кошелёк, когда его кто-то купит на Торговой площадке. Ключи продаются быстро, но не мгновенно. Поэтому при нескольких повторах подряд следующий круг может пропуститься, если денег на кошельке пока не хватает.

**Что такое maFile и нужен ли он?**
Не нужен. Это файл программы Steam Desktop Authenticator, которая заменяет мобильное приложение. С ним программе не придётся спрашивать код и не нужно будет подтверждать продажи в телефоне. Если он у вас есть, выберите в настройке Steam Guard вариант **2** и перетащите файл в окно.

**Это законно / безопасно для аккаунта?**
Покупать и продавать ключи можно. Но автоматизация (боты) может нарушать правила Steam. Используете на свой риск. Программа подтверждает **только** продажи на Торговой площадке и никогда не подтверждает обмены.

## Для продвинутых

### Команды

```bash
npm start                     # меню (то же, что start.bat)
npm run setup                 # пошаговая настройка
npm run price                 # цены и убыток на ключ
npm run run-cycle -- --keys 2 --cycles 3
npm run buy -- --keys 1
npm run sell
npm run confirm
npm run stats
npm run dashboard             # http://localhost:3000
npm test
```

В режиме команд (не в меню) действует `DRY_RUN` из `.env`. По умолчанию он `true`: покупки и продажи только симулируются.

### Настройки в `.env`

Меню само заполняет основные поля. Остальное можно поменять в файле `.env` (его можно открыть Блокнотом):

| Параметр | Что делает |
|---|---|
| `MAX_LOSS_PERCENT` | не покупать, если потеря на ключ больше этого процента (по умолчанию 25) |
| `DAILY_SPEND_LIMIT` | лимит трат в магазине за сутки, в центах/копейках (0 = без лимита) |
| `MIN_BUYER_PRICE` | не выставлять ключ дешевле этой цены |
| `SELL_ONLY_PURCHASED` | продавать только ключи, купленные программой (ваши собственные ключи не трогаются) |
| `UNDERCUT` | на сколько центов/копеек выставлять дешевле самого дешёвого лота |
| `POINTS_PER_UNIT` | очков за 1 единицу валюты (100 за $1), только для подсчёта |
| `STEAM_API_KEY` | если указан, цена ключа в магазине берётся автоматически |

### Как это устроено

| Файл | Назначение |
|---|---|
| `src/menu.js`, `src/setup.js` | меню и пошаговая настройка |
| `src/steam.js` | вход в Steam, Steam Guard, кошелёк |
| `src/gc.js` | подключение к координатору TF2 |
| `src/store.js` | покупка в магазине Манн Ко. (`StorePurchaseInit` → подтверждение → `StorePurchaseFinalize`) |
| `src/market.js` | цены Торговой площадки, инвентарь, выставление лотов |
| `src/fees.js` | расчёт комиссий Торговой площадки |
| `src/confirm.js` | автоподтверждение лотов через maFile (`identity_secret`) |
| `src/ledger.js` | журнал покупок/продаж `data/ledger.json` и статистика |
| `src/dashboard.js` | статистика в браузере |

### Ограничения

- Статистика считает **ожидаемую** выручку по цене выставления. Если лот долго не продаётся и цена меняется, реальная сумма может немного отличаться.
- Если Steam временно запретит продавать купленные ключи, продайте их позже через пункт **4**.
